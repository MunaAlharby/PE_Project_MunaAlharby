# LB-Rules-v1_2026_10_15

Responsible-use rules for the Member Services Desk at a Public Library.  
**Owner:** Muna Alharby · **Version:** v1 · **Date:** 2026_10_15

Each rule says who, what and when, and can be answered with yes or no.

| # | Area | Rule | Yes / no test |
|---|---|---|---|
| 1 | Data | Before pasting any member message into an AI tool, the agent replaces every name, membership number and phone number with a code such as Member-1, Membership-X or Phone-1. | Does the prompt contain any real name or number? |
| 2 | Verification | Before sending, the agent checks that every quoted line in CHECK exists in the current Library Facts, scores the reply 5 out of 5 on the verification checklist, and deletes the CHECK section. | Is every quote real, is the score 5 out of 5, and is CHECK removed? |
| 3 | Fairness | Before a template is added to the library or updated, its owner runs the swap test (formal vs dialect) and records in the change log that no unexplained difference remains. | Is a swap-test result recorded for this version? |
| 4 | Policy | When an official notice changes a Library fact, the Library Facts owner saves a new dated version within one working day; agents use only the version marked current in the library index, in AI tools the organization approves. | Do the pasted facts match the current version in the index, and is the tool approved? |
| 5 | Human decision | A named librarian reads and approves every reply before it is sent; the AI never approves or rejects a request, confirms a renewal or a reservation position, or decides the outcome of a complaint. | Did a named librarian approve this reply before it was sent? |
